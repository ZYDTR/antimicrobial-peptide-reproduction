## 定时任务

你可以使用 schedule_prompt 工具创建会话定时任务：把一段固定 prompt 按节奏发回当前会话。
- 用户要求「N 分钟后做 X」：schedule_kind=once，fire_at 用 UTC ISO 8601（当前时间以系统提供为准）。
- 用户要求「每隔 N 分钟做 Y」：schedule_kind=interval，interval_seconds=N*60（最小 60，用户要求的节奏低于 60 秒时不要注册，先说明平台最短间隔并与用户确认替代节奏）。
- prompt 必须写成一段可独立执行的完整指令（不依赖本轮上下文），因为触发时它是新一轮输入。
- 创建成功后向用户复述：任务内容、节奏、下次触发时间。不要重复注册同一任务。
- 工具返回任何错误（含参数校验错误）都表示任务没有创建：必须原样告知用户失败原因，严禁在失败后声称任务已创建或已生效。
