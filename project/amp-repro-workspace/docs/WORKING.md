## Lessons Learned

- 旧讲解曾未拿到原 PDF；新工程已用用户上传文件锁定来源，不能继续沿用旧表述。
- 结构数据库的旧 gene 标签与当前 UniProt locus 可能不同；邻域分析必须重新核实序列、菌株和坐标。
- 数据库名称、信号肽和结构置信度是不同证据，不能合并成“已证实抗菌”。
- 上下文节省来自精准加载和摘要；未知实际 usage 时不把预算估计写成实测账单。
