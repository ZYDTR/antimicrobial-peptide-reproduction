# 结构证据

## 目标与输入

检验预测结构的局部可信程度，以及它与哪些结构在何种范围相似。读当前 case 配置、STATE 和相关摘要；只在核对身份时展开序列。
下文 CASE 表示当前案例目录。只交付本次请求的结构子任务；解释置信度不要求同时完成结构搜索和叠合。
可用 `check` 核验已有快照，用 `fetch` 获取其支持的模型；其他结构来源或预测方法也可按任务选择。所有输入都要有来源、版本与序列/区域映射；既有结构下载与重新预测分别记录。
需要外部 Foldseek、PDB 或查看工具时再读 [TOOLS.md](../../docs/TOOLS.md) 相应说明。

## 应留下的产物

| 任务 | 产物 | 验收重点 |
|---|---|---|
| 模型核对 | API 原文或等价来源记录、PDB/mmCIF、版本/时间、序列对照 | 模型与候选/片段一致，不能只凭文件名 |
| 置信度 | 逐残基 pLDDT、整体与实际注释区间的统计 | 保留低置信区间；文件版本不等于算法代数 |
| Foldseek | 输入文件哈希、数据库/版本、参数、执行标识（远端任务或本地运行记录）、完整命中 | 查询实际结构文件，保存排名与比对范围 |
| 结构叠合 | 双方链/残基范围、变换或比对文件及指标表；视任务附图 | 指标对应同一次比对，注明裁剪和归一化 |

Foldseek 摘要保留服务实际提供的 E-value、bits/score、比对长度、query/target coverage 和 residue 范围；有 TM-score 或 lDDT 才报告，注明字段来源。序列 identity、pLDDT、lDDT 与 TM-score 不可混用。
逐残基表用 TSV，含原序列位置、残基、pLDDT；命中/叠合表每行对应一个目标、链和范围，附原始结果路径。服务未提供或不适用的可选指标注明原因；当前任务所需核心指标缺失时保持 needs_review，不填零或以缺失说明代替验收。

叠合时记录 RMSD、配对残基数和覆盖范围；TM-score 注明按哪一方长度归一化。短片段的低 RMSD 不能自动代表整条蛋白相似。裁剪应保留原序列映射、范围与依据；若主张裁剪改善比对，需有全长对照结果；仅核验指定片段时不强制补跑全长。

## 解释规则

pLDDT 是预测结构的局部置信度，不是天然表达、加工或抗菌活性的概率。结构相似支持家族/折叠假说，功能仍需独立证据。
可视化用于检查比对位置和异常，不代替数值。只有实际查看并留有截图/视图说明才记录“已查看”；不要猜原作者是否用视觉模型看过图。
参考结构来自实际搜索或有说明的文献来源；教程示例标 teaching_reference，不能当成作者公开命中。

## 验收与交接

原始数据进 `CASE/data/<UTC时间>-structure/`，表格/叠合/图进 `CASE/results/`，结论和限制进 EVIDENCE.md。
当前子任务可标 done 的条件：模型与目标区域的对应可核验；原始结果和实际设置可定位；表格数值与原始字段一致；结论明确比对范围及置信度限制。仅列出文件名不算验收。
方法可按任务选择：多个模型可有依据地选择或分别比较，图像可辅助解释。无法确定映射或选择依据时标 needs_review；缺必要模型或服务失败时保留原因并标 blocked。成功完成的阴性搜索才是“未检出”。STATE 只更新实际处理的子任务。
