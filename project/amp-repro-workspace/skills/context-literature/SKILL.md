# 基因环境与文献

## 目标与读取

按当前任务核验候选的基因组定位、邻域关系或相关文献，说明各类证据对功能解释的支持与限制。
基因邻域和文献是可独立执行的子任务；只按当前问题验收，文献任务不要求先完成邻域。下文 CASE 表示当前案例目录。
从 case 配置读取 genome_context 和候选标识，从 STATE 定位交叉引用；不把历史 gene 标签当作唯一身份。
需要 NCBI 或 PubMed 时再读 [TOOLS.md](../../docs/TOOLS.md) 对应说明；无关模型、PDB 和整份文献库不加载。

## 基因邻域的完成标准

目标记录保留 assembly/contig 及版本、菌株、protein ID、locus tag、CDS 起止、链方向与翻译序列哈希。邻域 TSV 或 Markdown 表每行一个 CDS，列坐标、方向、注释及证据路径；注明目标 CDS、邻域窗口和原始记录范围。缺失字段写未知及原因，身份无法确认时保持 needs_review。

先确认目标 CDS 翻译序列与候选一致，再谈“旁边”。这里指同一基因组序列上的位置关系，不是蛋白折叠后的空间接近。

保存原始 GenBank/GFF 或等价记录、实际范围和坐标约定。1-based inclusive 下，两个不重叠区间的间隔为后者 start − 前者 end − 1；负值解释为重叠。转录方向上的上游/下游需结合正负链。

assembly、菌株、CDS 或跨库映射不一致时标 needs_review，列出冲突和可分辨证据，不跨记录拼邻域。非冗余蛋白记录可能对应多个基因组，不是独立表达实验。
附近有运输或调控相关基因可形成假说；邻域注释本身也可能是预测，不能当作功能验证。
完成邻域核验的依据是：目标翻译与候选匹配、所列邻居属于同一已确认记录、间隔能从表中坐标重算、注释与推断分开。本项目已遇到旧结构记录 gene 标签与当前 UniProt locus 不同，见 [工程教训](../../docs/WORKING.md#lessons-learned)；遇到该差异应查序列与坐标，不能仅按名称拼接。

## 文献的完成标准

保存检索式、数据库、日期、筛选理由，并制作下表：

| 文献标识 / 链接 | 具体分子与物种 | 实验或计算方法 | 支持的主张 | 对本候选的限制 |
|---|---|---|---|---|

文献子任务的验收范围由当前问题限定：检索范围和纳入标准明确，纳入文献均有可定位来源，每条支持/反对/证据不足的判断对应具体内容。成功完成但无相关结果时，保存零结果及检索范围；不以“证明穷尽所有文献”为完成门槛。
优先原始研究和官方数据。家族成员的机制不等于本候选已证实相同机制。摘要不足以判断细节时标待全文核对；“没有检到”限定查询范围。
原文主张、候选直接证据、家族类比和推断分开。后续验证说明“要排除哪个解释、什么结果支持/反驳它”，不把待验证问题写成发现。

## 保存与交接

原始记录/检索响应进 `CASE/data/<UTC时间>-context/`，坐标表与文献证据表进 `CASE/results/`，主张及限制进 EVIDENCE.md。
STATE 分别记录基因映射、邻域核验、候选直接文献和家族背景的状态；查到家族文章不能把全部文献研究标 done。
获取或检索失败时保留原始错误与解除阻塞条件，相关子任务标 blocked；只有成功执行的检索才可解释为范围内未检出。缺必要全文或身份映射时交付已有证据并标 needs_review，不把缺失内容补成推断事实。
